# Halcyon Bay — сетевая игра (до 4 игроков)

Форк добавляет мультиплеер в версию **Ultracode** (игра *Halcyon Bay*): один игрок — хост, остальные
подключаются к нему по домашней сети или через Tailscale. Все бегают в одном мире, видят друг друга
(с именами над головой), ездят на машинах, в том числе вместе, и могут стрелять друг в друга.

## Как запустить

Нужен один файл `HalcyonBay_Multiplayer.exe` (у всех игроков — одна и та же сборка).

1. **Хост** запускает игру → вводит имя → **«Создать игру»**. При первом запуске Windows спросит про
   брандмауэр — нажмите **«Разрешить доступ»** (нужны UDP-порты 24565 и 24566).
2. **Остальные** запускают игру → вводят имя → в списке «Найденные игры» появится игра хоста →
   двойной щелчок (или кнопка «Подключиться»).
3. Если игра в списке не появилась — введите адрес хоста вручную. Хост видит свои адреса в правом
   верхнем углу экрана и в меню *Esc → Multiplayer* (или F6).

### Дома (одна сеть Wi-Fi / кабель)
Игра хоста находится сама. Адрес вида `192.168.x.x`.

### С друзьями через Tailscale
1. Все ставят Tailscale и входят в одну сеть (tailnet), либо хост делится своим устройством.
2. Хост создаёт игру. У друзей игра появится в списке автоматически (игра опрашивает устройства
   tailnet). Если нет — ввести Tailscale-адрес хоста вида `100.x.y.z`.

Хостом лучше делать самый мощный компьютер: он считает трафик, пешеходов и всё окружение.
Слабому ноутбуку (встроенная графика Intel/AMD) лучше быть клиентом — игра сама включит на нём
облегчённые настройки графики (их можно поменять в *Esc → Settings*).

## Управление в сети

| Клавиша | Действие |
|---|---|
| `F` рядом с машиной друга | сесть к нему **пассажиром** |
| удерживать `F` | выкинуть друга из-за руля и угнать машину |
| `N` (держать) | список игроков, убийства / смерти, пинг |
| `Esc → Multiplayer` или `F6` | меню сети: адреса, игроки, выйти из игры |

Остальное управление — как в одиночной игре (WASD, мышь, `F` — транспорт, `Tab` — оружие, `F1` —
админ-меню, где можно выдать себе оружие и машины).

## Как это работает

- Смерть: как в одиночной игре — «DOWN» и возрождение у больницы. В ленте слева видно, кто кого.
- Розыск у каждого игрока свой: полиция гонится за тем, кто нарушал.
- Трафик и пешеходы общие (их считает хост), появляются вокруг каждого игрока.
- Пауза в сетевой игре не останавливает мир.
- Клиент не использует и не портит одиночное сохранение.

## Известные ограничения

- Подбираемые предметы, разрушаемые мелочи, двери, трамвай, животные и такси у каждого игрока свои
  (не синхронизируются). Такси и «скорая» работают только у хоста.
- Если хост выходит, игра у остальных заканчивается (перезапуск в стартовое меню).
- Версии игры у всех должны совпадать.

## Запуск с параметрами (необязательно)

```
HalcyonBay_Multiplayer.exe -- --host --name=Папа
HalcyonBay_Multiplayer.exe -- --join=192.168.1.20 --name=Сын
HalcyonBay_Multiplayer.exe -- --solo
```
Другие: `--port=N`, `--max-players=N` (2–8), `--lowspec` / `--no-lowspec`.
Если на видеокарте проблемы с картинкой: `HalcyonBay_Multiplayer.exe --rendering-driver vulkan`.

## Для разработчиков

Код сети — `Ultracode/gta/code/net/`. Тест на одной машине (хост + клиент):
`Ultracode/tools/mp_test.sh <Godot console exe> <папка логов> [window]`.
Сборка: `godot --headless --path Ultracode --export-release "Windows Desktop" build/HalcyonBay_Multiplayer.exe`.

## macOS и Linux

В релизе есть сборки для всех трёх систем; играть можно вместе (Windows + macOS + Linux).
Эти две сборки собраны на Windows и на самих macOS / Linux **не запускались** — если что-то не так, сообщите.

- **Linux (x86_64):** `HalcyonBay_Multiplayer.x86_64`. Нужен Vulkan.
  ```
  chmod +x HalcyonBay_Multiplayer.x86_64
  ./HalcyonBay_Multiplayer.x86_64
  ```
- **macOS (Intel и Apple Silicon):** `HalcyonBay_Multiplayer_macOS.zip`. Распакуйте. Приложение не
  подписано Apple, поэтому при первом запуске: правый щелчок по приложению → «Открыть» → «Открыть».
  Если macOS пишет, что приложение повреждено, выполните в Терминале
  `xattr -dr com.apple.quarantine "<путь к приложению>.app"`.
